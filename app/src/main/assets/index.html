SpotifyAlt

Classic heart controls for Android

1. Spotify developer setup

Create a Spotify developer app and add this exact redirect URI:

http://127.0.0.1:43821/callback

Paste the app's Client ID below. SpotifyAlt uses PKCE, so no client secret is needed.

2. Android media access

Notification access allows SpotifyAlt to find Spotify's active MediaSession and forward previous, play/pause and next.

3. Start companion controls

Start playback in Spotify, then start the companion. SpotifyAlt will publish its own media notification with a true Liked Songs heart.

What the heart means

  • ♡ — current Spotify track is not in your library.
  • ♥ — current Spotify track is actually saved in your library.
  • Tapping it only changes the real saved state. It never means “in some playlist.”
